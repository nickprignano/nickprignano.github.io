# nickprignano.github.io

Redirects only. The AVD repos moved to the [avd-ops](https://github.com/avd-ops) org, and GitHub
redirects a moved repo but not its Pages site. This user site catches the old
`nickprignano.github.io/<repo>/...` links and forwards them to `avd-ops.github.io/<repo>/...`
(`404.html` for any path, plus plain pages for the portals that work without JavaScript).

To cover another moved repo, add its name to `moved` in `404.html`.

Personal project, not for production, provided as is, not affiliated with the author's employer,
Liquidware or Microsoft.
